# Chess

A live game between strong players, move by move, from [Lichess TV](https://lichess.org/tv).

- **The board** on the left, from the featured player's side, with the last
  move's squares lit. White's pieces are white, Black's are red.
- **The players** above and below, with titles (GM, IM…) and their clocks, the
  side to move ticking down in amber.
- **The move just played** in big letters ("Nf3", "exd5", "O-O").
- When a game ends, Lichess features the next one and the screen introduces the
  new players with their ratings.

One open stream from Lichess's free TV feed: no account, no key.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/chess
```

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `channel` | `best` | The Lichess TV channel: `best` (the top game right now), `bullet`, `blitz`, `rapid`, `classical`, `chess960`… |
