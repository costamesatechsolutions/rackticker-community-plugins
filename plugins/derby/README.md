# Derby night

A horse race that runs itself, the way a sportsbook shows it. Every visit is a new race:

1. **Post time**: the race number drops in, then the tote board: eight horses in
   their saddle-cloth colours with the morning line.
2. **The gate**: the doors open, *and they're off*.
3. **The race**: the camera follows the leader past the rail posts and the quarter
   poles, the field strings out, front runners fade and closers come late. The
   running order updates along the bottom with the race clock.
4. **Photo finish** when it is close: the flash, the frozen picture at the wire,
   and the board waiting for the stewards.
5. **Official**: the first three with what a $2 ticket paid to win, place and show.

The favourite wins about a third of the time, as at a real track, and longshots
sometimes get up. It is a show: nothing is real and nothing is bet.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/derby
```

No settings. Add it to the playlist; each visit plays one whole race (about 37 seconds).
