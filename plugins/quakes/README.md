# Quakes

Quakes: earthquakes around you, from the U.S. Geological Survey.

A seismograph drum of the last 24 hours with a spike for every quake (taller for
bigger ones), then the latest shakes: magnitude, where, how far from you and how
long ago. A quake at or above the alert size within the alert distance takes
over the display once.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/quakes
```

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `radius_miles` | `250` |see the control page |
| `alert_magnitude` | `4.0` | A quake this size or bigger within the alert distance takes over the display |
| `alert_miles` | `100` |see the control page |
