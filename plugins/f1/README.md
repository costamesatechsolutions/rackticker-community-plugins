# Formula 1

Formula 1: a start-light gantry counting down to lights out, the last race's podium and the championship fight. Key-free Jolpica (Ergast-compatible) API.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/f1
```

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `timezone` | `America/Los_Angeles` | Time zone |
| `refresh_seconds` | `900` |see the control page |
