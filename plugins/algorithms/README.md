# Algorithms

Computer science you can watch.

- **Sort race**: the same 64 shuffled bars, coloured from red to blue, on both
  halves of the panel. Two sorting algorithms put them in order at exactly the
  same pace, one comparison or move per tick, with the bars being compared lit
  white and a running count. One fast algorithm (quicksort, merge, heap or shell
  sort) is always in the race against anything from bubble sort up, so you can
  see what "n log n" means.
- **Maze**: a maze carves itself across the whole panel (a depth-first
  backtracker), a flood spreads out from the green entrance until it reaches the
  red exit (breadth-first search), the shortest path lights up in gold and a
  runner takes it.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/algorithms
```

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `mode` | `auto` | `auto` shows a sort race then a maze; or just `sort` or `maze` |
