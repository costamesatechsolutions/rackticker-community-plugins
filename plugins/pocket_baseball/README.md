# Pocket baseball

A made-up Orange County league that is always playing: the Costa Mesa Tacos, the
Long Beach Lighthouses, the Huntington Surf, the Anaheim Oranges, the Irvine
Owls, the Santa Ana Winds, the Newport Pelicans and the Laguna Waves.

A game is on whenever you look, run by the clock, so it carries on while the
screen shows other things, like a game on the bar TV:

- **Play ball**: the matchup.
- **Every plate appearance, pitch by pitch**: the diamond with the runners on
  base and the outs, the batter, the count, each pitch called (ball, strike,
  foul, in play), then the result ("DOUBLES", "HOME RUN!", "DOUBLE PLAY") and
  any runs that scored, with the hit flying off the bat.
- **The line score**: runs inning by inning and the total for both teams.
- **Final**, extra innings and walk-offs included, then the next game.

A new game starts every eight minutes. Outcomes follow big-league rates, so a
team scores about four runs a game and the box scores look like real ones.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/pocket_baseball
```

No settings.
