# Tanks

Tanks: real levels as water that sloshes.

California's big reservoirs, from the state's CDEC data (daily storage against
capacity), and the International Space Station's urine tank from NASA's public
live telemetry whenever that stream is answering. Each tank is a small wave
simulation: the surface ripples, rocks now and then, and bubbles rise.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/tanks
```

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `reservoirs` | `SHA,ORO,FOL,CLE` | California reservoirs by CDEC code: SHA Shasta, ORO Oroville, CLE Trinity, NML New Melones, SNL San Luis, DNP Don Pedro, FOL Folsom, PNF Pine Flat |
| `iss` | `True` | Also show the space stations urine and water tanks when NASAs live feed answers |
