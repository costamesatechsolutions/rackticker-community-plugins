# LED sign

Programmable LED sign: the storefront kind that spells words out of flying pixels, drops letters in, spins slot reels and chases marquee bulbs.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/ticker_wall
```

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `style` | `auto` | auto takes turns: taqueria (taco parade), Vegas (slot machine), arena, Times Square. One of `auto`, `taqueria`, `vegas`, `arena`, `times_square` |
| `words` | `` | Your phrases, separated by / ; a / splits one into beats. Empty uses each style's classics |
| `scene_seconds` | `8` | Longer holds each phrase longer |
