# Arcade

Ambient arcade: real games, played live by simple AIs at native resolution.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/arcade
```

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `mode` | `auto` | auto rotates through every game. One of `auto`, `quest`, `tetris`, `snake`, `breakout`, `invaders`, `pong` |
| `scene_seconds` | `30` | Seconds per game in auto mode (8–180) |
