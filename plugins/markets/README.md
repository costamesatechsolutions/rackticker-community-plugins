# Prediction markets

Read-only public prediction-market odds board; no trading capability.

## Install

Paste this **folder URL** into RackTicker → Plugins → Add a plugin:

```
https://github.com/costamesatechsolutions/rackticker-community-plugins/tree/main/plugins/markets
```

## Settings

| Setting | Default | What it does |
| --- | --- | --- |
| `refresh_seconds` | `90` |see the control page |
